# Asking For Help

If you encounter issues/bugs, here's what you can do:

1. **Check if it isn't original game behaviour** - BostonUnlocked is meant to replicate the vanilla game as closely as possible. Any deviation not mentioned in [Features and Limitations](/features_limitations) counts as a bug. To check if the issue wasn't in the original game, here are some resources:
    * [All NPC and Mission Dialogue](https://steamcommunity.com/sharedfiles/filedetails/?id=859974620)
    * [Video of a complete playthrough of the game](https://www.youtube.com/playlist?list=PLJeCfXtw78_9YzNM4QrABDO0jiI0gWQ8Q)

If you aren't sure, discuss it on Discord or log it as a bug (see below for how).

2. **Reporting a bug** - See [Report bugs](/reportbugs).

3. **Talk to us on Discord** - You can reach out to us directly in the [Community Discord](https://discord.gg/cyuPZrC8Wr) in the `#support` channel.
