# Quick Start Guide

The fastest way to play the game is to connect to our community server which is where most of the community is active and is always kept updated. Here's how:

1. Join our [Community Discord](https://discord.gg/cyuPZrC8Wr)
2. Go to the `#how-to-connect` channel to get the community server address to use
3. Follow the instructions in [Connect to Another Server](/connectmp) to patch the game to use that server address and have fun!

::: info
We do not mention the server address directly on the website to protect it from automated scrapers which might misuse the information.
:::

::: info
You can also run your own server (offline single-player, online multiplayer, connect to another multiplayer server). Refer to the "Server hosting options" in [Features and Limitations](/features_limitations#features) for how.
:::
