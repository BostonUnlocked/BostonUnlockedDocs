## 2026-11-26 HALLOWEEN and BONUSCOSMETICS Coupon Codes, Server and Site updates

Hoi Chummers! Here's a news roundup from our last website update:

### HALLOWEEN and BONUSCOSMETICS Coupon Codes

Some new coupon codes have been added:

1. HALLOWEEN will give you the coveted Halloween exclusive 🎃 pet.

2. BONUSCOSMETICS adds several cosmetics that aren't obtainable through other missions. This has quite a few items that players when the game was officially available may have remember but haven't been able to get. As ShadowAid couldn't determine how these items are unlocked from the game code alone, they have been made available as a coupon pack redeemable by anyone instead.

All you need to do is put these into the coupon section of the launcher (same way you activated the DLCs) and your characters should have the items show up when the log in! Happy Halloween! 🎃

### Server updates

1. Multiple bug-fixes on the server to address issues like character avatar duplication in the hub and being sent to an incorrect hub after a co-op mission in some scenarios
2. Server-side testing features
3. The Server Status Page now supports HTTPS as well as HTTP

2. The section about DLC and chat commands in [Connect to Another Server](/connectmp) and [Play Single Player Offline](/installsp) has been expanded with helpful commands for a first run and how to find players to group with. Thanks to [Nerva's Discord post](https://discord.com/channels/1233507112081166376/1233507112521306143/1574354525362593864) for highlighting these!
3. [Play Single Player Offline](/installsp) lists Python 3 as an additional dependency. Thanks [MellowD](https://discord.com/channels/1233507112081166376/1476089872279142411/1536071049236717579) for reporting this!
4. The [Quick Start Guide](/quick_start) has been updated to remove references to the server being in alpha and include a link to the features page for other gameplay options (offline single player, etc).
5. Misc. typo corrections and template updates to remove the HTTP limitation for the server status page

Have fun, there are more exciting things being developed!
