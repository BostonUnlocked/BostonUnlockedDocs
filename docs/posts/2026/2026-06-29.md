## 2026-06-29 More Chat Commands, Community Server Moved to the MADE, Misc. Updates

Hoi Chummers, we have some interesting new features added to BostonUnlocked along with a major infrastructure change.

[[toc]]

### New Chat Commands

New chat commands have been added to allow deleting your account (should you want to) using the `/deleteaccount` [Global Chat Command](/commands_player). Administrators can now also set the number of career slots using the `/setcareerslots` and `/othersetcareerslots` [Admin Global Chat Commands](/commands_admin). Please refer to the documentation for limitations and bear in mind the delete account command is irreversible!

Speaking of chat commands, the respec command from our [last announcement](/posts/2026/2026-04-21) seems to have been received positively so far. If you have any further feedback about it, let us know on the Discord server!

### The Community Server is now hosted at the MADE

The Community Server has now moved to hosting at the MADE. ShadowAid has worked tirelessly to ensure the move went smoothly and the migration preserved all player data. If your installation was using the previous intermediate update posted on the Discord server where you were asked to use `sro.shadowaid.com`, that address already points to the new server IP and your game should be working fine. If you had not updated your server IP, you will need to use the new URL mentioned in the `#how-to-connect` Discord channel instead of `sro.shadowaid.com` and repatch your game to reconnect to the server. We do not expect the final URL on the Discord to change anytime soon.

### Miscellaneous Updates

Other updates include:

1. The [Project History](/project_history) page has been updated to include the Community Server setup history.
2. Some additional diagnostic logging was added to the server.
3. Various pages were updated to indicate that you can use an IP or a URL when patching the game to connect to a BostonUnlocked server.
4. [Interesting Game Behaviour](/gameref/interesting_finds#empty-loot) was updated to include a situation where you can get empty loot, thanks to EMELT for pointing this out!

Enjoy, we have some more exciting things in the pipeline!
