::: tip Enable DLC, check Chat Commands and LFG
1. Once you launch the game for the first time, don't forget to [Enable DLC](/enabling_dlc).
2. [Global Chat Commands](/commands_player) (and if you are an [admin](/enable_admin), [Admin Global Chat Commands](/commands_admin)) are available to you once you login to the game. Some highlights:

* By default, your account's display name is a random hexadecimal string. You can change this by using the [Set Account Nname global chat command](/commands_player#setaccountname).
* The [Reset Skills global chat command](/commands_player#resetskills)  allows you to respec your character once every 28 days.

3. If you want to find other runners, you can ask in the Global Chat in-game. The Server Status Page (detailed in [Features and Limitations](features_limitations.md)) can help with determining who is available outside the game. The `#lfg` channel in the [Community Discord server](https://discord.gg/cyuPZrC8Wr) can also help find players to group with. If the latter is not visible in the Discord server's channel list, enable it by visiting `⁠Channels & Roles` in the Discord server and activate it there.
:::
